# Document 5: Engineering Standards
**HERA v1.0 Enterprise Architecture**

## 1. API Conventions (REST Standards)
* All APIs must use strict `Zod` validation middleware before controller execution.
* **Pagination:** Cursor-based pagination for large datasets; offset pagination allowed for admin tables. Responses must wrap data: `{ data: [], meta: { nextCursor } }`.
* **RBAC:** Every mutative route (`POST`, `PUT`, `DELETE`, `PATCH`) must implement `authorizeRole(['ADMIN', 'EDITOR'])` middleware.

## 2. Prisma & Database Conventions
* **Soft Deletes:** Every canonical entity must have a `deletedAt DateTime?` field. Hard deletes (`prisma.entity.delete`) are strictly forbidden. Use `prisma.entity.update({ data: { deletedAt: new Date() } })`.
* **Naming:** Models are `PascalCase` singular (e.g., `MasterArtisan`). DB tables are snake_case.
* **UUIDs:** All primary keys must be `uuid` generated by database (`dbgenerated("gen_random_uuid()")`). Auto-increment IDs are banned to prevent enumeration attacks.
* **Slugs:** Generated at creation, stored globally unique, lowercase, hyphenated.

## 3. Workflow & Versioning
* Content entities use an `enum Status { DRAFT, IN_REVIEW, VERIFIED, PUBLISHED, ARCHIVED }`.
* Major entities must support shadow version tables to retain full history of changes for scholarly accountability.

## 4. Error Handling
* Standardized API error responses: `{ error: { code: "VALIDATION_FAILED", message: "...", details: [] } }`.
* No stack traces exposed in production.

## 5. Security & Observability
* **Rate Limiting:** Mandatory on all public GET endpoints. Stricter limits on POST (e.g., Auth, Submissions).
* **Logging:** Use structured JSON logging (Winston/Pino) feeding into Datadog/ELK. All mutative actions must write to `DashboardAuditLog`.

## 6. Git Workflow
* Trunk-based development. Feature branches must be named `feature/service-name/description` or `fix/service-name/description`.

## 7. Media & Caching
* **Caching:** CDN edge caching for public GET requests. Redis for heavy dashboard analytics.
* **Media:** Never serve raw video from the backend container. Use presigned S3 URLs or Mux HLS streams.
